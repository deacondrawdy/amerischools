# amerischools.org

The AmeriSchools Academy website: Astro 5 + Tailwind 4, rendered by a small Node server on
Railway. Pushing to `main` deploys.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Local dev server |
| `npm run build` | Production build into `dist/` |
| `npm start` | Run the production server (`dist/server/entry.mjs`) |
| `node scripts/qa-check.mjs <base url>` | Launch QA: every page, every old amerischools.org URL, 404s, robots and sitemap |

## Railway setup

| Variable | Purpose |
| --- | --- |
| `STAFF_PASSWORD` | The shared password for the website editor at `/staff/` |
| `STAFF_FILES_DIR` | Folder on a Railway **volume** where editor changes are saved, e.g. `/data/staff` (volume mounted at `/data`). Without it, production refuses saves, because the container disk is wiped on every deploy. |

`railway.json` and `nixpacks.toml` hold the build and start commands.

## Where things live

- **Website editor** (`/staff/`, same design as the Capstone Quest site): announcement bar, campus
  details, page text (Markdown) and new pages, photo replacement and alt text, PDF replacement.
  Code in `src/pages/staff/` and `src/lib/staff/`; the Marketing how-to guide is `/staff/help/`.
- **Tracking and forms**: IDs in `src/data/marketing.ts` (GA4, Meta Pixel, Google Ads, HubSpot).
  Add `?track_debug=1` to any page URL to log every tracked event to the browser console.
- **Redirects**: `public/_redirects` (generated by `scripts/migrate-legacy.mjs`, applied by
  `src/middleware.ts` as real 301s). Old URLs are listed in `scripts/legacy-urls.txt`.
- **PDFs**: `files/documents/`, served by `src/pages/documents/[...path].ts` so a replaced PDF keeps its URL.
- **Content**: `src/data/` (campuses, photos, curriculum, contact) and `src/content/pages/` (migrated pages).
